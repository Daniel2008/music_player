# 可靠性与性能修复（2026-10-23）

本轮按确认顺序处理代码审查问题，再测绘制和内存。沿用当前 feature 分支，保留既有未提交修改；未提交、推送或部署。测量使用隔离存储、500 条测试队列及合成音频，不修改个人曲库和播放记录。

## 可靠性结果

| 问题 | 修复与验证 |
| --- | --- |
| 同名下载覆盖文件、共享临时文件 | 每个任务独立临时目录，预留不冲突的目标名，不覆盖已有文件；真实本地 HTTP 并发测试验证内容和原文件保留。 |
| 慢播放请求覆盖新选择 | 本地检查、远程解析、原生加载共用请求代次；串行释放旧资源；自动下一曲检查选择和代次是否变化。测试覆盖旧请求成功、失败及停止的交错。 |
| 退出前保存未完成 | 窗口拦截关闭，停止播放后等待全部保存；保存期间阻止界面编辑；失败保留窗口，可重试。测试覆盖重复关闭、等待和失败。 |
| 损坏存储未恢复、错误被吞 | 空文件、结构和解码错误统一回退备份，恢复后保留健康备份；写错误向上传递并通知界面；未修改的未知新版本不回写。 |
| 下载设置重启丢失 | 目录、并发数、自动开始持久化；关闭自动开始后提供开始等待任务入口；并发 flush 等待最新一批写入。 |
| 清除歌词缓存无效 | 删除应用管理的磁盘歌词缓存并更新版本；保留曲目旁的用户歌词；隔离临时目录测试验证。 |
| 初次本地播放、单曲循环入口不一致 | 控制条、全屏、快捷键、系统媒体控制复用智能播放；无句柄时加载曲目，过期 URL 清缓存后刷新。 |
| 无调用旧代码 | 删除旧 v2 页面和转码器；旧页面原有局部修改保存在 docs/legacy-player-workspace-v2.patch，完整副本在 build/verification。 |

验证：完整 122 项测试通过；`dart analyze` 无问题；Windows Profile 构建成功。独立复查发现的关闭保存竞态已先用阻塞写入测试复现，再修复并通过回归。

## 性能测量边界

原始报告与原始数据保留在 docs/performance-2026-10-23.md 和 build/verification/performance。原报告的 35–40ms 栅格 P95 与本轮控制组存在环境差异，不能直接作为本轮收益基线。

本轮前台控制组在 build/verification/performance-desktop-control：150% DPI、普通窗口 1904×1191、全屏 2560×1600；霓虹柱 P95 27.57ms、瀑布谱 28.09ms、全屏 22.08ms。试验改动将动态频谱与静态状态栏分开重绘，缓存瀑布单元几何并合并重复幂运算。最终收益必须以前台复测为准。

内存证据：控制组闲置时 Dart 堆约 31MiB，进程 RSS 约 951MiB；另一轮最小化运行在频谱阶段 Dart 堆约 19MiB，进程 RSS 约 859MiB。采样不同时，不能据此计算精确组成，但可排除“RSS 全部来自 Dart 堆”的解释。未证明内存泄漏，也不强制清除引擎缓存或手动 GC。音频可视化采样缓冲改为首次可视化时创建。

## 有效前台复测

用户恢复窗口后重新启动同一 Profile 构建。已确认普通窗口可见、瀑布画面随真实音频更新；两组物理尺寸与 DPI 一致。优化后数据在 build/verification/performance-after，共 7 个阶段、119 条进程和 109 条 GPU 样本，Flutter 错误为零。上一轮最小化数据移至 performance-after-minimized，不用于对照。

| 场景 | 控制组栅格 P95 | 优化后栅格 P95 | 变化 | CPU 整机均值：前→后 | GPU 最忙引擎均值：前→后 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 霓虹柱 | 27.572ms | 23.579ms | -14.5% | 4.86%→5.01% | 37.16%→39.30% |
| 瀑布谱 | 28.088ms | 24.620ms | -12.3% | 4.99%→5.26% | 36.09%→42.75% |
| 全屏霓虹柱 | 22.082ms | 19.816ms | -10.3% | 4.57%→4.68% | 33.44%→35.25% |

CPU 按 24 个逻辑处理器归一化；GPU 列为该进程最忙引擎，非整卡利用率。以上为单轮前后观测，不能排除温度、系统负载和缓存状态波动；控制组与优化后构建均已含可靠性修复，因此也不能用这组数据量化延迟创建采样缓冲的收益。

保留动态层重绘隔离和瀑布几何复用：本轮观察到绘制尾延迟改善，没有证明整体 CPU/GPU 降耗。三个动态场景 P95 仍超过 16.67ms，未达到稳定 60fps 验收。

进程采样峰值 RSS：1347.9→1272.3MiB（约 -5.6%）；闲置阶段峰值 1020.7→989.3MiB。应用内阶段末尾 RSS 则为 950.2→921.8MiB；采样时间不同，不能混用。优化后闲置 Dart 堆 23.7MiB、容量 28.9MiB、external 约 22KiB。暂停后 15 秒只记录 1 帧；闲置 CPU 约 0.09%、GPU 最忙引擎约 0.12%。短测未证明持续泄漏，原生/引擎内存仍高，需要后续针对图形资源和缓存的长时间分配分析。

已完成本轮修复、绘制优化与前台短测。长期稳定性、Release、多 DPI 和 macOS/Linux 未验收；内存高占用仍保留为后续问题。
